Eika Army Crowd Overlay V8 — Updated Test Build

This is a FULL project archive based on the existing CrowdOverlay package, with the targeted reduced-stacking / grounded crowd update and the Mara + Yukzz___ special-avatar registrations. Existing assets, connector, package files, and Twitch integration files are retained.

TEST
1. Extract the entire folder.
2. Start it using the included Run_Eika_Army_Overlay.bat (or your normal server startup method).
3. Open http://127.0.0.1:8081/?demo=1 to test demo controls.
4. Use your normal stream URL in OBS after testing.

Demo controls included: Add roster character, Add special avatar, N3Koyama fly, Talk test, Remove one, Crowd cheer, Clear crowd. Character limit: 50.

Mara and Yukzz___ are registered as special avatars, but their sprite folders must contain assets/Special Avatars/Mara/idle.png and assets/Special Avatars/Yukzz___/idle.png respectively for their custom sprites to display. The existing archive did not contain those two idle sprites, so this build does not fabricate them.

Validation: JavaScript syntax checked and demo button IDs checked against the updated app. This is not a live OBS/Twitch test.
