Eika Army Crowd Overlay — Special Avatar Test Fix + N3Koyama Fly Button

Install: back up your current app.js and index.html, then replace them with the versions in this patch. Copy the included assets/Special Avatars/n3koyama/fly and landing folders into the matching assets folder in your overlay. Keep the existing style.css and all other assets.

In demo mode (?demo=1), the roster is populated but special avatars are no longer pre-added automatically, so the Add special avatar button can add one at a time. Press S to add the next available special avatar. Click “Make N3Koyama fly” or press F to add N3Koyama if needed and trigger flight. If he is still entering the screen, flight starts once he reaches his spot.

Flight uses the six supplied fly frames and six supplied landing frames. Takeoff uses N3Koyama's assigned idle sprite; flight/landing phases are triggered by the button and also occur automatically every roughly 4.5–5.5 minutes when idle.
