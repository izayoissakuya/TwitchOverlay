Conversation animation assets for Celestia

Add six transparent full-character frames named exactly:
  frame_01.png
  frame_02.png
  frame_03.png

  frame_05.png
  frame_06.png

Folder: assets/celestia/conversation/
The six frames play in a loop at 6 frames per second while this character is conversing.
Keep the character's feet, framing, and scale aligned across all frames so the animation does not jitter.
Make the character face sideways toward their conversation partner; the overlay mirrors the sprites for left/right facing.

For backward compatibility, a single talk.png is still accepted if the six numbered frames are not all present. If neither set is available, the normal idle sprite is used.
